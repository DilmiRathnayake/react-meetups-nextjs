# React Meetups App 🚀

A full-stack demo project built while learning **React.js**, **Next.js**, and **MongoDB**.  
This application allows users to manage meetups by adding, editing, deleting, and viewing meetup details with image previews.

## 🔧 Technologies Used
- React.js
- Next.js
- MongoDB
- CSS Modules
- API Routes (Next.js)
- Server-Side Rendering (SSR) & Static Site Generation (SSG)

## ✨ Features
- Add new meetups using a form
- Edit existing meetup details
- Delete meetups
- View meetup images and details
- Dynamic routing with Next.js
- API integration with MongoDB
- Responsive UI

## 🎯 Purpose
This project was developed as a **learning-focused demo application** to understand:
- Full-stack development with Next.js
- Database integration using MongoDB
- Routing, data fetching, and deployment concepts

Completed – open for improvements and feature enhancements.
